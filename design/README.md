# Design references

- `town-maps/` – the "Tebura-chō town maps" design canvas: the town overview, the six chapter area plans, and every phone screen (join, controller, home, messages, map, diary, dictionary, jobs, phone, incoming call, camera, おうち) plus the TV views for the camera and the house. Each `.dc.html` file is one artboard; `canvas.json` is the layout. They open in the design canvas on claude.ai, not on their own.
- The sprite art and the flat scene pictures from the "mock sprites" canvas are in `../assets/source/`.
- The game design plan lives in Claude Docs ("Un-Handy Man — Game Design Plan"); use its Export menu for Markdown, Word or PDF.
